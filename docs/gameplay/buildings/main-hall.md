# Main hall

One headquarters; starts built, fires arrows, and supplies 0.8 wood, 0.45 stone,
0.1 gold per game second. Destruction ends the game. Cannot be dismantled.
Base HP 4200, damage 42, range 500, period 1.1 seconds. Preserve these values.
Panel: health, attack stats, actual upgrade effects and costs; no Workshop tutorial.
Local upgrades on its own panel. Preserve purchased levels on migration.

Level-one upgrade price: 65 wood / 45 stone / 25 gold. Later upgrade
prices scale by 1.15^(current level - 1), rounded up per resource.

The Main hall advances the settlement through eight pre-modern ages. Age
advancement is a separate purchase on the Hall. The current age determines how
buildings look and which tower improvements the Workshop can research. Starting
a new settlement begins in Wood. Existing Hall upgrade levels, earned damage
and HP carry forward when loading an earlier settlement.

The Age tab lets the player compare a building's current and next paintings
at the same scale before buying. The illustrated selection starts with the
Hall and can be changed without spending supplies. On reaching Crown the
player can inspect each fully advanced building. For new Workshop projects,
show the actual next-age research painting beside the project name. The
price and Advance action remain in a fixed position, separate from browsing.
