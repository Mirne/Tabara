# Main hall

One headquarters; starts built, fires arrows, and supplies 0.8 wood, 0.45 stone,
0.1 gold per game second. Destruction ends the game. Cannot be dismantled.
Base HP 4200, damage 42, range 500, period 1.1 seconds. Preserve these values.
Panel: health, attack stats, actual upgrade effects and costs; no Workshop tutorial.
Local upgrades on its own panel. Preserve purchased levels on migration.

Level-one upgrade price: 65 wood / 45 stone / 25 gold. Later upgrade
prices scale by 1.15^(current level - 1), rounded up per resource.
